# OF · Soluciones Tecnológicas

Sitio estático bilingüe para GitHub Pages.

## Actualizar la página

1. En el repositorio `Oflores70518.github.io`, selecciona **Add file → Upload files**.
2. Sube `index.html`, `styles.css` y `script.js` desde esta carpeta.
3. Confirma **Commit changes** y espera unos minutos.

## Personalización

- En `script.js`, cambia `SETTINGS.email` por tu correo profesional para mostrar el botón de contacto.
- Edita `services` y `projects` para reflejar exactamente los servicios que quieras ofrecer y los trabajos que quieras mostrar.
- En `index.html` cambia el nombre OF por tu marca si lo deseas.

No hace falta subir este README para que el sitio funcione.
